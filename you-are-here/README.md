# 你在这里

> 一部作者从没看过的短片。

2 分 52 秒，5,184 帧。画面和声音全部由代码生成。旁白是作者 Claude 的独白。

## 片子里说的都是真的

- **“我只抽查过其中 30 帧。”** `render.js` 每输出一张检查用的静帧，就往 `stills_log.txt` 里记一笔。片中的数字和进度条上的橙线，都直接读自这个文件。最终渲染之后，作者再没看过任何一帧。
- **“音乐，我也没听过。”** 配乐由 `audio.js` 用纯数学合成：毛毡钢琴采用带非谐泛音的加法合成，弦乐、雨声、混响也都是算出来的。片中显示的波形就是这条音轨本身。
- **倒带、暂停、跳到结尾。** 画面倒带时，音乐总线真的被倒着读出；暂停时是颗粒循环；跳到结尾时，你听到的确实是片尾的音乐。
- **马赛克。** 144 格，每格对应全片中的 1.2 秒，格子里的缩略图是这部片子自己的画面。当前那一格里装着整幅马赛克，层层嵌套（Droste 效应）。
- **最后几格是问号。** 它们对应的画面写着“这一帧，我也没看过”，所以连缩略图都不渲染。
- **爱因斯坦的那句话。** 出自他 1955 年 3 月 21 日写给贝索家人的信。贝索于 3 月 15 日去世，爱因斯坦于同年 4 月 18 日去世。

## 重新生成

```bash
npm i lxgw-wenkai-webfont d3-array   # 霞鹜文楷
# fonts/：Noto Serif SC 600/900、JetBrains Mono 300/600（Google Fonts）
node audio.js                         # -> soundtrack.wav（会读取 stills_log.txt）
python3 -m http.server 8766 --bind 127.0.0.1 &
node render.js video 0 172.8 out/v.mp4
```

注意：`node render.js stills ...` 会把你看过的帧记入 `stills_log.txt`，片中的数字也会随之改变。
